SUPER MELEE 64 — 0.6.0-beta.7 / NATIVE14

This source-only beta builds the game locally from your own game files. It
includes the installer, original integration source and project artwork. No
ROM, ISO, extracted character assets, game binary, saves or recordings are
included. Read LICENSE, LICENSING.md and THIRD-PARTY.txt before distributing.
Public source: https://github.com/memelees/super-melee-64

YOUR GAME FILES
SM64: original US big-endian .z64 ROM, 8 MiB.
SHA-1: 9bef1128717f958171a4afac3ed78ee2bb4e86ce
Melee: unmodified USA Rev 2 ISO/GCM, GALE01 revision 2.
MD5: 0e63d4223b01d9aba596259dc155a174
Other revisions, NKit/RVZ, patched discs and byte-swapped ROMs are unsupported.
The build adapter is bundled. Setup downloads pinned public engine source and
verified official Akaneia/Melee3D patches. No private repository login is needed.
Your game files stay local and are never modified in place or uploaded.

MAC — APPLE SILICON, macOS 15+
The latest macOS is not required. macOS 26.4 is within the supported range.
Intel Macs are not supported. Beta.8 fixes beta.7's accidental macOS 27
installer minimum; both the executable and its app metadata now target 15.0.
1. Extract the Mac kit and open Install Super Melee 64.app.
2. Drop BOTH game files into the window, or choose them. Select Build / Resume.
3. Setup checks prerequisites, prepares missing Homebrew packages and a private
   Python environment, verifies the tools and continues the build automatically.
   Prepare Build Tools also runs this preparation separately. If Apple tools or
   Homebrew are absent, finish the official setup instructions, then retry.
4. Setup installs Super Melee 64.app into /Applications, or your personal
   ~/Applications folder if shared Applications is not writable. The completion
   screen shows the installed path, with Open Game and Show in Finder buttons.
   Before installing, setup checks every bundled native-library dependency and
   runs the packaged game through 180 gameplay frames with an isolated save.
   A failed startup check preserves the existing app and reports the cause.

Allow at least 12 GiB free; 20 GiB is recommended. The initial source build
can take a while. Cancel stops the current operation and keeps verified
checkouts/downloads for Resume. Use the setup log when reporting a failure;
review it for personal paths before sharing.

This beta has an ad hoc signature, without Apple notarization. macOS may block
a downloaded helper. Apple's instructions for a trusted downloaded app:
https://support.apple.com/en-us/102445
The game itself needs no Python, Homebrew or terminal after installation.

Manual prerequisites: Xcode Command Line Tools, Homebrew, Python 3.12+, Pillow,
gcc-16, GNU Make 4+ (gmake), mingw-w64 (SM64 sound assembler/objcopy/objdump),
CMake, Ninja, SDL2/SDL3, GLEW, pkg-config, xdelta3, 7-Zip, Git, patch,
and curl. Prepare Build Tools checks these and guides missing steps.
CLI (extract to a directory without spaces):
  python3 Setup.py --platform mac --rom /path/game.z64 --melee /path/game.iso
Add --check for an input/prerequisite check without downloads or a game build.
Use --check-tools for prerequisites alone. Setup Mac.command also supports CLI.

MAC BUILD-TOOLS REPAIR
Setup selects Apple's active macOS SDK explicitly, including when resuming an
older failed build, and checks both the Melee GCC compiler and Apple C++ headers
before downloading game dependencies. A stale SDKROOT from a shell is replaced
with the SDK reported by xcrun. The source-only header checks run no game code.
If the check fails, the app shows repair instructions and writes the compiler
details to setup.log. The installer never accepts Apple's licence for you.

- Xcode licence/setup: open Xcode, review the licence and finish its prompts.
- Outdated tools or missing headers: install the Apple Command Line Tools update
  from System Settings > General > Software Update; open Xcode if you use it.
- Missing GCC: choose Prepare Build Tools to install Homebrew's GCC compiler.
- Missing gmake or a level_rules.mk directory error: choose Prepare Build Tools
  in the latest installer. It installs Homebrew's GNU Make. Apple's bundled
  Make 3.81 cannot run the pinned source's build preparation. Manual repair:
    brew install make
- Missing i686-w64-mingw32-as, objcopy or objdump: choose Prepare Build Tools
  in the latest installer. Both Mac hosts use these GNU tools to build SM64's
  sound data; this does not make the game a Windows app. Manual repair:
    brew install mingw-w64
Then choose Prepare Build Tools and Build / Resume in the SAME build folder.
Existing game inputs, downloaded patches and build outputs are preserved.
When updating the installer, extract the new kit and open its new installer app;
select the original build folder so its updated setup source can resume there.
Source updates compare file contents and clear generated Python caches, so
reproducible ZIP timestamps cannot leave an older installer backend in use.
Open Setup Log opens setup-gui.log, including errors before compilation starts.
The window title and new log entries show the installer version.
If setup stops, the message explains the cause and the next repair step, with an
error code and installer version. Mac users can choose Copy Error Details.
Pre-build failures such as low disk space also have a saved diagnostic; you do
not need to find a compiler traceback to understand the problem. If the message
does not identify the cause, send the latest setup log and error details.

WINDOWS — EXPERIMENTAL x64 WINDOWS 10/11 BETA
1. Extract the complete Windows kit to C:\SuperMelee64 (no spaces/OneDrive).
2. Open Setup Windows.cmd and choose Prepare Build Tools. Follow Microsoft's
   prompts for the VC++ x64 runtime and WSL/Ubuntu 24.04. Finish Ubuntu's first
   run and restart Windows if requested, then retry Prepare Build Tools.
3. Select/drop both game files and build. WSL is used for compilation.
4. Open Super Melee 64.lnk. The native launcher/game need no Python or WSL
   during gameplay. Keep the build log if setup fails.

Requires DirectX 12 for Melee and working OpenGL for the SM64 host. The complete
Windows game, installer GUI, recording and online play still need real Windows
hardware testing. Cross-compilation and launcher unit tests are narrower checks.

PLAY / SAVES
New Playthrough starts from zero stars; Continue resumes it. Unlocked is a
separate sandbox. Recommended stage starts have separate earned-star saves;
collecting a star returns to that course's SM64 star selector. The included
Recommended Playthrough.html lists character/stage pairings and a checklist.
Default uses authored encounters. Impossible forces every CPU to level 9.
No Melee Enemies keeps SM64's original enemies and bosses.

Keyboard: WASD move, L jump, comma attack, K special, Q/E up/down modifiers,
left Shift grab, right Shift shield, arrows camera, Enter Start.
Controller: A attack, B special, X/Y jump, LB up modifier, LT down modifier,
RB grab, RT shield, D-pad camera.
F6 / controller Back: change character/costume using native portraits.
F7: summon a chosen CPU (up to three).
F8 / L3: summon one authored stage round, cycling through its saved rounds.
       A deliberate press replaces current Melee opponents. Manual rounds
       wait for another press; ordinary story waves advance after clearing.
F10: toggle wall jumps for every fighter. Default OFF; native abilities remain.
Fighters use circular ground shadows. Height lines/rings and their toggle have
been removed; old saved line settings are ignored.
The Mac Gameplay menu also exposes these actions. Toggles persist per profile.

WATER / CAPS / TRAVEL
Ordinary swimming holds depth; idle fighters sink. Q/LB/L1 rises; E/LT/L2 dives.
Jump near the surface to leap out. Jumps and specials remain available in water.
The SM64 AIR meter is separate from Melee damage. Coins restore air by original
coin value and heal ten Melee percentage points per value. Applied damage costs
one air wedge per eight damage points; blocked hits cost no air. Warm surfacing
refills air; cold water drains faster. CPUs and Nana have independent air.
Metal caps use Melee's Metal appearance and stop passive air change. Vanish
uses cloak transparency. With a Wing cap, up modifier + jump activates native
SM64 flight. Shells use SM64 riding rules. Cannons launch Melee tumble on an
SM64-scale arc; aerial actions can interrupt it. Knockback leaves Melee trails.

CO-OP — EXPERIMENTAL, UP TO 16 HUMAN SEATS
Mac Gameplay > Host Co-op or Join Co-op; enter the host IP. Every person needs
the same beta and locally supplied game files. Choose fighters independently.
Default port: 7777. LAN/direct IP is the initial connection method. Internet
hosting requires suitable router/firewall configuration; there is no public
matchmaking service bundled in this beta.

Only SuperMelee64-native14-beta1 clients are compatible. Stock Coop Deluxe and
older builds cannot join. Rebuild everyone from the same source kit. Characters,
projectiles, sounds, damage, shields, grabs and throws have native sync paths.
One peer simulates each shared stage encounter; others display its state.
F7/F8 requests are shared and round progress survives encounter ownership changes.
CLI: python3 outputs/sm64-melee-lab/native/play_coop.py --character sonic --host
Use --join HOST_IP instead of --host, and --costume for the initial outfit.

Remote Lua/mod/file exchange is disabled. Packet bounds and sender admission
have regression checks; this is not a complete hostile-peer security audit or
competitive anti-cheat system. Play with trusted peers while beta testing.
Sixteen slots are implemented; a sixteen-person session has not been tested.
Advanced reflection/counter/item interactions and high-latency combat need
more testing. Read SECURITY.md before enabling Internet access.

RECORDING
F9 or Mac Recording > Start / Stop Recording (Command-Shift-R). Record ON in
the picker arms recording. Mac: ~/Movies/Super Melee 64. Windows:
outputs/sm64-melee-lab/Recordings. Recording captures game video/audio. Stop or
quit normally to finalize MP4. Mac's fragmented MP4 retains completed fragments
following a crash. Mac Command-Shift-O opens the recordings folder.
