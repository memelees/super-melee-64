SUPER MELEE 64 — SOURCES, ATTRIBUTION AND DISTRIBUTION BOUNDARIES

This is an unofficial fan modification. It is not affiliated with Nintendo,
HAL Laboratory, SEGA, or the owners of the depicted characters.

The package includes integration scripts/patches and original branding.
It does not include original game assets, extracted assets, engine binaries,
commercial game images, or another player's saves or recordings. Character
art in previews is generated locally from player-supplied game data and is
not included in the downloadable source kit.

Important source notice
The melee-pc licenses/LICENSE.md distinguishes its GPL-3.0-or-later port
code from its unlicensed Nintendo/HAL decompiled game code. Its notice says
that permission to redistribute the latter is not offered. Supplying a disc
at setup does not turn that notice into a binary redistribution license.
That is why this kit fetches upstream separately and builds only on the
player's machine; no complete native engine binary is shipped here.

COPYING-port.txt preserves the upstream GPL text for applicable port work.
UPSTREAM-LICENSING.txt preserves the exact upstream licensing explanation.
Those files do not relicense game code/assets or grant rights on behalf of
their owners. The integration's existing notices remain applicable; no blanket
license for Nintendo/HAL/SEGA assets or decompiled code is claimed.

The Super Melee 64 logo is newly rendered artwork inspired by the games,
packaged into transparent icons by native/build_branding.py. It does not
include extracted Nintendo logo meshes or commercial font files. The runtime title scene is extracted locally from
the player's SM64 ROM. The game uses original title geometry/backgrounds
locally; those assets are not in the release kit.

The beta records its tested setup and runtime scope in the release notes.
Windows remains experimental; source/patch provenance and upstream notices
do not amount to a blanket licence for the combined game engine.
